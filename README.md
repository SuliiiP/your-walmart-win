# Your Walmart Win

create a quiz landing page for a sweepstake affiliate offer called Walmart $750. The

offer converts the best for audience aged 25-44 years old and it is US only offer. Here is a

link to the offer page: https://giftclick.org/aff_c?offer_id=1911&aff_id=173888 make it mobile

optimized. Make it a quiz lander with 2 questions that will qualify the viewers and get

them into the mindset of already doing something towards the reward at the end,

answering questions and then filling out their basic personal info. Make the questions

relevant to the offer, targeting people who wanna save on clothing. The only thing that's not allowed is to guarantee that people are actually

gonna get the the shopping credit. Headline should directly name the action people have to

do, such as Apply For Walmart $750 Today. Use similar design, colors as the

offer page so the transition then from the lander to the offer page isn't so big.
